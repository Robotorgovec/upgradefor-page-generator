# Agent Notes

## UPGR 3D Logo

When the user asks to place, attach, emboss, engrave, render, or overlay the UPGR logo in Blender, CAD, 3D scenes, equipment models, decals, branded renders, or similar assets, use the canonical project sources in `assets/brand/upgr-logo-3d/source/`.

Start with `assets/brand/upgr-logo-3d/source/upgr-logo.blend` for Blender work. STEP, SolidWorks, M3D, and a Blender backup are stored in the same folder for CAD/import fallback.
