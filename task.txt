Обнови tools/upgr_agent_gui.py.

Цель:
Сделать отдельные кнопки для верхнего поля задачи и нижнего окна логов, чтобы ускорить работу и убрать лишние клики.

Требования:

1. Верхняя область = Task editor
Добавить отдельные кнопки для верхнего поля:
- Paste Task
- Copy Task
- Clear Task
- Select All Task

Поведение:
- Paste Task:
  - одним кликом очищает верхнее поле
  - вставляет в него текущее содержимое буфера обмена
- Copy Task:
  - копирует весь текст верхнего поля в буфер обмена
- Clear Task:
  - полностью очищает верхнее поле
- Select All Task:
  - выделяет весь текст верхнего поля

2. Нижняя область = Live output / log panel
Добавить отдельные кнопки для нижнего окна:
- Copy Log
- Clear Log
- Select All Log

Поведение:
- Copy Log:
  - копирует весь текст нижнего окна в буфер обмена
- Clear Log:
  - очищает только видимый лог в GUI
  - не удаляет файлы логов на диске
- Select All Log:
  - выделяет весь текст нижнего окна

3. Горячие клавиши
Для верхнего поля задачи:
- Ctrl+A = выделить всё
- Ctrl+C = копировать
- Ctrl+V = вставить
- Ctrl+X = вырезать
- Shift+Insert = вставить
- Ctrl+Insert = копировать

Для нижнего окна логов:
- Ctrl+A = выделить всё
- Ctrl+C = копировать
- Ctrl+Insert = копировать

4. Контекстные меню по правому клику
Для верхнего поля:
- Copy
- Paste
- Cut
- Select All
- Clear

Для нижнего окна:
- Copy
- Select All
- Clear

5. Ограничения
- Нижнее окно логов должно остаться read-only
- Не изменять другие файлы, кроме:
  - tools/upgr_agent_gui.py

6. UX
- Кнопки верхнего поля и нижнего окна должны быть визуально разделены
- Подписи должны быть понятными
- Интерфейс не должен выглядеть перегруженным

7. После выполнения:
- остановиться
- кратко указать, какие кнопки добавлены
