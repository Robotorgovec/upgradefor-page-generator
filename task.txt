Создай backend для v5 multi-step агента.

Цель:
Сделать планировщик, который разбивает большую цель на шаги и выполняет их последовательно через существующий auto-codex.ps1.

Разрешено менять только:
- tools/upgr_v5_orchestrator.py
- при необходимости tools/__init__.py
- runtime/goal.txt
- runtime/plan.md
- runtime/state.json
- runtime/tasks/**
- runtime/reports/**

Не изменять:
- auto-codex.ps1
- tools/upgr_agent_gui.py
- app/**
- components/**
- public/**
- prisma/**

Требования:
1. Создать tools/upgr_v5_orchestrator.py
2. Он должен:
   - читать runtime/goal.txt
   - если plan.md отсутствует, создавать план шагов
   - создавать task-файлы для шагов в runtime/tasks/
   - запускать шаги по очереди через auto-codex.ps1
   - обновлять runtime/state.json
   - при ошибке останавливаться
   - в конце создавать runtime/reports/final-report.md
3. Формат state.json должен хранить:
   - текущий шаг
   - статус плана
   - статусы шагов
4. Каждый шаг должен быть маленьким и изолированным
5. После выполнения вывести краткую инструкцию запуска:
   - как задать goal
   - как запустить orchestrator
   - где смотреть state и report

После выполнения остановиться.
