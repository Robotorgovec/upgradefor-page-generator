# UPGR 3D Logo Sources

Canonical source assets for the UPGR logo used in Blender, CAD, renders, overlays, decals, embossing, engraving, and other 3D branding work.

## Files

- `source/upgr-logo.blend` - primary Blender source, saved with Blender 3.03.
- `source/upgr-logo.blend1` - Blender backup from the original source set.
- `source/upgr-logo.step` - CAD exchange source.
- `source/upgr-logo.sldprt` - SolidWorks part source.
- `source/upgr-logo.m3d` - original M3D source archive.

## Usage Note

For Blender or 3D placement requests, start from `source/upgr-logo.blend`. Use `source/upgr-logo.step` when a CAD-style import/export path is a better fit. Existing SVG logo files in the project are still fine for flat web/header usage, but this folder is the source of truth for 3D logo work.
