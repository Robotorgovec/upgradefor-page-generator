# Learning games sitemap

Runtime `/sitemap.xml` is generated by `app/sitemap.ts`.

`public/sitemap.xml` is not a source of truth anymore and is intentionally removed to avoid runtime conflicts.

Learning-game sitemap URLs are composed in `lib/learning-game/sitemap.ts`, including:
- legacy URLs previously listed in the static sitemap,
- canonical `/learn` URLs,
- published/indexable glossary card URLs.

`tests/learning-game/http.test.ts` validates runtime sitemap entry generation from `app/sitemap.ts` and URL allow/block rules.
